# Tic-Tac-Toe Game in C++

## About
A console-based Tic-Tac-Toe game developed using C++.

## Features
- Two-player gameplay (X and O)
- Dynamic 3×3 game board
- Winner and draw detection
- Input validation
- Replay option

## Concepts Used
- Arrays
- Loops
- Conditional statements
- Functions
- Basic input/output

## How to Run
Compile using a C++ compiler:

`g++ tic_tac_toe.cpp -o tic_tac_toe`

Run the generated executable on your system.

## Objective
To demonstrate fundamental C++ programming concepts through an interactive mini-game.
